LUMMAN ENERGY WEBSITE
=====================

Main site: index.html
Domain: lummanenergyie.com

FASTEST DEPLOYMENT (VERCEL)
1. Sign in to Vercel with GitHub.
2. Create a new GitHub repository called "lumman-energy-site".
3. Upload the contents of this folder to the repository (not the outer folder itself).
4. In Vercel, choose "Add New > Project" and import that repository.
5. Framework preset: Other. No build command. Output directory: leave blank.
6. Deploy.
7. In Vercel Project > Settings > Domains, add lummanenergyie.com and www.lummanenergyie.com.
8. Vercel will show the DNS records required. Add those records in your Squarespace Domains DNS panel (Google Domains accounts were migrated there).

IMPORTANT: QUOTE FORM ACTIVATION
The quote form uses FormSubmit to email lummanenergy@outlook.com, including uploaded files.
The first submission triggers a verification email. Open that email and click the activation link.
Until you activate it, real submissions will not be delivered normally.
FormSubmit states total uploaded file size must not exceed 10 MB.

Before launch, submit a test quote yourself from the live site and confirm that all 3 files arrive.
